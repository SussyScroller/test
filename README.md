# RedGifs Audio Patches

A tiny, standalone patch source that contains a single patch: **Enable RedGifs audio** for
Reddit (`com.reddit.frontpage`). It is made to be used **together with** the official
Morphe patches, in the same patching run, without forking them.

Compatible with Morphe. Not affiliated with or endorsed by the Morphe project.

## Credits

The patch was written by **[DarkGooner](https://github.com/DarkGooner)** in their fork
[DarkGooner/morphe-patches](https://github.com/DarkGooner/morphe-patches) (ported from
release `v1.47.9`, commits `8703c7d8f` to `547e06151`). All of the patch logic is theirs.
This repository only repackages it as a standalone patch source. See [NOTICE](NOTICE).

## What the patch does

Reddit plays RedGifs posts using its own audio-less transcode. This patch looks up the
original RedGifs video through the RedGifs API (`api.redgifs.com`, temporary token, `sd`
file preferred over `hd`) and swaps that url into Reddit's own video player, so the video
plays with sound. Older RedGifs posts that Reddit would open in the browser are made to
play in the app.

Differences from DarkGooner's version:

- No settings toggle. The patch is always on once applied. To turn it off, re-patch without it.
- No dependency on the official settings patch (which pulls in Spoof signature and more),
  so it does not apply any of the official patches a second time.
- Self-contained extension (plain `HttpURLConnection`, `android.util.Log`, `Looper`) in its
  own package and extension file name, so it can't collide with the official extension.
- Errors are logged to logcat under the tag `RedGifsAudio` (no toasts). Debug logging is off
  by default: `adb shell setprop log.tag.RedGifsAudio DEBUG` turns it on.

## Supported versions

Only Reddit **2026.24.0** is declared and tested.

## How to use

### Morphe Manager

Add this repository as a patch source next to the official Morphe source. Once a release
exists, use https://morphe.software/add-source?github=SussyScroller/test, or add the
`.mpp` file as a local patch source. Then patch Reddit with both sources enabled.

### Morphe CLI (desktop)

```
java -jar morphe-desktop-*-all.jar patch \
  -p https://github.com/MorpheApp/morphe-patches \
  -p patches-<version>.mpp \
  reddit-2026.24.0.apkm
```

Each `-p` adds a bundle. Name-based `-e`/`-d` flags apply to the bundle they follow.

## Maintenance notes

- **RedGifs API changes** (auth endpoint, response JSON, token rules, user agent):
  `extensions/redgifs/src/main/java/app/sussyscroller/redgifs/extension/RedGifsAudioPatch.java`
  (`API_URL`, `getToken`, `fetchVideoUrl`, `USER_AGENT`, `REDGIFS_ID_PATTERN`).
- **Reddit version changes** (fingerprints fail, or the patch applies but videos stay silent):
  `patches/src/main/kotlin/app/sussyscroller/patches/reddit/redgifs/Fingerprints.kt` and
  `RedGifsAudioPatch.kt`. Reddit model classes the extension calls (constructors and getters
  of `Link`, `Preview`, `RedditVideo`, ...) are stubbed in `extensions/redgifs/stub`. If
  Reddit changes them, update the stubs and the extension. The supported version list is in
  `patches/src/main/kotlin/app/sussyscroller/patches/shared/Constants.kt`.
- Check DarkGooner's fork first. They may already have fixed it upstream.

## Building locally

Building needs read access to GitHub Packages (`maven.pkg.github.com/MorpheApp/registry`),
where the Morphe Gradle plugin and patcher are published. Create a GitHub *classic* personal
access token with only the `read:packages` scope
([create one here](https://github.com/settings/tokens/new?scopes=read:packages&description=Morphe)), and put it in `~/.gradle/gradle.properties`
(your user Gradle home, not this repository):

```
gpr.user=<your GitHub username>
gpr.key=<the token>
```

Or set the `GITHUB_ACTOR` and `GITHUB_TOKEN` environment variables. You also need JDK 17+
and the Android SDK (platform 36), with `ANDROID_HOME` set or `sdk.dir` in `local.properties`.

- Run `./gradlew buildAndroid`
- The built patches .mpp file is found in `patches/build/libs/patches-*.mpp`
